ORELHA HUB
===========

Arquivos:
- ORELHA_HUB.lua: painel para Roblox Studio.
- loader.lua: exemplo de carregador para hospedagem.

IMPORTANTE:
Esta versao foi escrita para ser usada como LocalScript no seu proprio jogo,
em StarterPlayer > StarterPlayerScripts. O ESP e a mira assistida sao limitados
a NPCs do proprio jogo. O circulo FOV e um indicador visual.

Para usar no Roblox Studio:
1. Abra o Roblox Studio.
2. Em Explorer, abra StarterPlayer > StarterPlayerScripts.
3. Insira um LocalScript.
4. Cole o conteudo de ORELHA_HUB.lua.
5. Teste com Play.

Para criar uma URL RAW:
1. Crie um repositorio no GitHub chamado ORELHA_HUB.
2. Envie ORELHA_HUB.lua para a branch main.
3. Abra o arquivo no GitHub e clique em Raw.
4. Copie a URL RAW e substitua a URL de exemplo em loader.lua.

O loader.lua e apenas um exemplo; loadstring/HttpGet nao e o fluxo recomendado
nem necessario para LocalScripts no proprio jogo.
